# DUOC-Assist EA2

## Descripción

Proyecto desarrollado para la Evaluación Parcial N°2 de la asignatura Ingeniería de Soluciones con IA.

El sistema implementa un agente académico basado en LangChain, capaz de consultar información institucional mediante recuperación de contexto utilizando RAG (Retrieval Augmented Generation).

## Funcionalidades

* Consulta de información académica.
* Recuperación de contexto mediante búsqueda semántica.
* Uso de base vectorial FAISS.
* Memoria simple para mantener continuidad en la conversación.
* Respuestas basadas en documentación institucional.

## Tecnologías utilizadas

* Python
* Google Colab
* LangChain
* FAISS
* HuggingFace Embeddings

## Estructura del proyecto

* `duoc_assist_agent.ipynb`: notebook principal con la implementación del agente.
* `README.md`: documentación del proyecto.

## Ejecución

1. Abrir el notebook en Google Colab.
2. Ejecutar la instalación de dependencias.
3. Ejecutar las celdas en orden.
4. Realizar consultas académicas al agente.
